# 后台管理

服务起来后访问 **`/admin`**（本机就是 http://127.0.0.1:8000/admin ，手机换成对应地址）。

## 鉴权

- **走用户账号，没有单独的口令**：必须先用普通账号登录，而且那个账号 `is_admin = 1` 才能进后台。不是管理员访问 `/admin` 会被打回登录页。
- **默认管理员**：第一次启动时自动创建（用户名 / 密码见 `.env` 的 `TAFFY_ADMIN_NAME` / `TAFFY_ADMIN_PASSWORD`）。登录后在「用户管理」里可以改自己的密码。
- **登录状态**：随机 token 的 cookie（HttpOnly + SameSite=Lax），**库里只存 token 的 sha256**，30 天有效。服务重启不会掉登录态。

## 导航

左侧可折叠的分类导航，折叠状态记在浏览器里（换设备要重折一次）。导航项只有文字、没有图标；顶栏右上角「收起导航」能把整条侧边栏收起来。地址栏带 `#/xxx`，可以直接收藏某个面板。

| 分组 | 面板 | 干什么 |
|---|---|---|
| 概览 | **仪表盘** | CPU / 内存 / 磁盘、本进程占用、负载，5 秒自动刷新 |
| 概览 | **访问流量** | 站点 PV / 独立 IP / 地区 / 热门路径 / 状态码，带按天趋势；点 IP 看日志明细并让模型分析；风险扫描；一键封禁 |
| 模型与接口 | **模型** | 聊天 / 图片两套模型名（带历史记录）+ 上下文上限 |
| 模型与接口 | **接口与 Key** | 聊天 / 图片 / 检索翻译三套 `base_url` + key |
| 模型与接口 | **向量模型** | 向量配置 + 总开关 + 单条输入上限 + 索引状态 |
| 模型与接口 | **工具开关** | 按组开关 12 组工具（关掉的组模型看不见、硬调会被拦） |
| 模型与接口 | **配置总览** | 部署相关配置一页看清：当前值 / 默认值 / 在哪改 / 要不要重启 |
| 人设 | **身份卡** | 新建 / 编辑 / 启用 / 删除身份卡 |
| 人设 | **系统提示词** | 直接改当前身份卡的提示词，新会话立刻生效 |
| 素材 | **表情包库** | 增删表情包、单张上传、zip 批量导入 |
| 文件 | **知识库文档** | 往 `knowledge/` 传 / 删文档，传完自动重启重建索引 |
| 文件 | **工作区文件** | 往 `workspace/` 上传、浏览子目录、删文件 / 目录 |
| 用户 | **用户管理** | 用户列表 / 建号 / 开权限 / 封号 / 重置密码 / 备注 / 删号 |
| 系统 | **检查更新** | 从 Gitee（默认）或 GitHub 拉最新版，更新完自动重启 |

存哪：项目根目录的 `admin.json`（已 gitignore——里面有明文 key，别提交）。没配过的项自动回落到 `.env` / `config.py`，所以这个文件删掉也不会坏。

生效时机：模型、key、接口地址**立刻生效，不用重启**（每次请求现问的）。**只有向量模型那张卡例外**：改完要重启，因为索引得重算。

## 仪表盘

数据全部从 `/proc` 和 `shutil.disk_usage` 现读，**不装 psutil**。CPU 用两次采样相减算，内存看 `/proc/meminfo`（含 swap），磁盘看 `workspace/` 所在分区，另外还显示本进程的 RSS、可用内存和最长的负载值。进度条超过 85% 会变橙提醒。

**Windows 上会显示「—」**：`/proc` 只有 Linux 有，这台系统读不到 CPU / 内存 / 进程那几项，磁盘照常。部署在 Linux 服务器上才全有。

## 系统提示词（人设）

身份卡的「人设」就是系统提示词——每个新会话历史里的第一条。点开能整段改：

- 框里显示的是**当前身份卡**的提示词（`personas/<id>/prompt.md`）。
- **所有身份卡共用的硬约束**在「人设 → 共享约束」里改（[config.py](../deck/config.py) 的 `CORE_PROMPT`），换身份卡不会把它换掉。
- **保存后新开的会话立刻生效，不用重启**。已经在聊的会话还留着旧的（第一条消息在开会话时就定下来了），想换就点聊天页右上角「新会话」。
- 改过的存在 `admin.json` 里（不进 git），**更新代码不会冲掉**；点「恢复内置的」回到 `config.py` 那份（二次确认）。
- 上限 40000 字（`settings.PROMPT_LIMIT`），超了直接拒绝——`admin.json` 每次都是整份读写，塞个几兆进去会把后台拖慢。
- 内置那份里标着「【重要】」的都是硬规矩（每轮必须发表情包、代码要完整写进回答、workspace 不许留临时文件、数学公式用 LaTeX、只准碰 workspace 里的文件……）。**删掉这些规矩它就真会照做**，改之前建议先把内置那份复制出来备份。

> 命令行那版（`python agent.py`）用的是同一份 `admin.json`，所以后台改完，终端里新开的会话也是新的人设。

## 表情包库

图片放在 `deck/web/static/stickers/`（由 `/static` 直接提供，前端和后台用的是同一批）。**文件名就是它的情绪**：

```
心情 + 序号 + 后缀        例：happy1.gif、love_02.png、think-3.webp
```

- **开头那段字母就是心情**，只能是这八个：`happy`、`think`、`confused`、`proud`、`cry`、`angry`、`sleepy`、`love`。后面接什么都行（数字、下划线、横杠），**认不出心情的会被跳过**（比如 `cat1.png`）。
- 后缀只收 `.png` / `.jpg` / `.jpeg` / `.gif` / `.webp`，单个 ≤ 8MB。
- 序号只是给你自己排的，**撞名不会覆盖**——会自动跳成 `happy4-2.png`。

**zip 批量导入**：压缩包 ≤ 80MB，一次最多 500 张、解压后总量 ≤ 200MB（防 zip 炸弹）；**子目录会一起扫**（`nested/proud7.png` 也认），`__MACOSX/`、隐藏文件、非图片自动跳过。导入完会列出「加进去哪些、跳过哪些、为什么」。

前端拿的是 `GET /api/stickers`（公开接口），**新加的刷新页面就能用**，不用重启。换身份卡后表情包也跟着换——每张卡一套。

## 知识库文档

给 `knowledge/` 传 / 删文档用的，**不用再手动 scp + 重启**。可以传子目录（`books/xxx.pdf` 这样填路径）、删单个文件或整个目录（递归）。支持的后缀跟知识库一致，**认不出的直接拒掉**，免得往库里塞一堆解析不了的东西。单个文件 ≤ 200MB，上传走**请求体裸流**、每 64KB 落盘，不占内存。

**传完 / 删完会自动重启服务**：索引是进程内建的，不重启新文档查不到。但不是一改就重启——按**「最后一次改动后 8 秒」**计时（可重置的 debounce），连着传好几个文件也只在最后重启一次。面板上会明确告诉你「已经在排队重启了」还是「重启命令是什么」。

> 服务得由 systemd 管着才能自动重启（跟「检查更新」一个前提）；命令行起的进程它会让你自己重启。

## 工作区文件

给 `workspace/` 传文件用的（就是 `list_files` / `read_file` 看的那个目录）。可以进子目录、上传、删文件或整个目录（递归），单个 ≤ 100MB。

**上传走请求体裸流、文件名放 query**（`POST .../upload?path=xxx`），后端每 64KB 写一次盘——**不在内存里攒整个文件**，小内存机器也扛得住。路径同样过沙箱检查，`../` 这类越界会被拒。

## 检查更新

选 Gitee / GitHub（**默认 Gitee**）→ 后台 `git fetch`，比较本地 `HEAD` 和远端分支：

- **有更新**：列出落后的提交和条数，点「立即更新」执行 `git pull --ff-only`——**只快进，绝不 force / reset / stash**，本地改过的东西不会被冲掉；冲突会如实报错，不会硬来。
- **拉完自动重启**：先 `systemctl is-active <服务名>` 判断能不能自动重启（能就 `systemctl --no-block restart`，2 秒后执行，好让当前这个 HTTP 响应先发出去）；**不是 systemd 起的**（比如自己 `python -m deck.web` 跑的）就把重启命令显示出来，要你手动。
- 服务名默认 `taffy-agent`，用 `TAFFY_SERVICE_NAME` 可以改。
- 远端按 **URL 里有没有 `gitee.com` / `github.com`** 自动认（不认 remote 叫什么名字）；选的那家记在 `admin.json` 里，下次打开还是它。
- **只 clone 了其中一家也能拉另一家**：`config.py` 里留了一份 `GIT_MIRRORS`（两家各一个地址，能用 `GITEE_URL` / `GITHUB_URL` 覆盖）。找不到对应厂家的 remote 时，直接拿这个地址 `git fetch <url> <分支>`（**只读，不改你本地的 remote 配置**，ref 用 `FETCH_HEAD`）。
- 拉取有 120 秒超时，并设了 `GIT_TERMINAL_PROMPT=0`——**要输账号密码会直接失败，不会把服务挂在那儿等输入**。

> **拉下来 ≠ 立刻生效**：新代码要等进程重启才跑得起来。不重启的话，静态文件已经是新的、后端还是旧的，就会看到「接口 404」「知识库那行数字显示成 —」这类怪事（后台会把这种 404 直接翻译成「多半是没重启」）。重启完记得刷新页面。
>
> **更新不会动你自己传的东西**：`.cache/`（含数据库）/ `admin.json` / `.env` / `workspace/` 都不在 git 里；后台传的表情包、身份卡（`personas/`）和知识库文档（`knowledge/`）都是**未跟踪文件**，`git pull --ff-only` 碰都不会碰。唯一会被拦的情况是**你手动删改过仓库里本来就有、已被 git 跟踪的文件**，那 git 会拒绝快进并报错，**不会硬覆盖**；想继续就先自己 `git stash` 或提交。

## 用户管理

看所有用户 / 邀请码 / 邀请人 / 注册时间 / 最后登录 / 会话数；建号、给谁开管理员、**封号（可选时长）**、重置密码、写备注、删号。

**封禁时长**：点「封号」填 `30m` / `12h` / `7d` 或 `0`（0 = 永久）。临时封禁**到期自动解封**，不用手动点；列表里会显示「已封号（2 小时后解封）」。被封的账号**立刻踢掉所有登录态**（下一次请求就是 401）。

护栏：不能取消自己的权限、不能封自己、不能删最后一个管理员。
