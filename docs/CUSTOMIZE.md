# 定制指南

这份文档讲「怎么把它改成你自己的」——换人设、换模型、关功能、搬机器。
**大部分事情后台点一点就能改，不用动代码。**

---

## 1. 换人设（身份卡）

人设现在叫**身份卡**，一张卡 = 一套人设：名字、称呼、欢迎语、状态文案、提示词、表情包。

### 怎么建

**后台 → 人设 → 身份卡 → 新建**，填：

| 字段 | 说明 | 例子 |
|---|---|---|
| ID | 目录名，建完不能改（小写字母开头，2~24 位）| `neko` |
| 名字 | 聊天页标题/顶栏显示的名字 | `猫猫` |
| 自称 | 人设里怎么称呼自己 | `猫猫` |
| 称呼用户 | 人设里怎么称呼用户 | `铲屎官` |
| 欢迎语 | 聊天页第一条消息 | `喵～有什么事吗` |
| 输入框提示 | 输入框占位文字 | `和猫猫说点什么喵…` |
| 在线文案 / 思考文案 | 状态栏那两句话 | `在线喵` / `正在思考喵…` |
| 提示词 | 整段人设（几千字），留空就用内置那份 | … |

保存后点 **「启用」**，聊天页刷新一下就是新人了。

### 存在哪

```
personas/
  deck/                  ← 默认身份卡（第一次启动自动生成）
    persona.json          ← 名字、称呼、欢迎语这些
    prompt.md             ← 提示词正文（后台编辑的就是它）
    stickers/             ← 这张卡自己的表情包（默认卡指回 static/stickers）
  neko/
    ...
```

- `personas/` 在 `.gitignore` 里，**属于部署数据**，`git pull` 不会碰
- 提示词优先读 `prompt.md`，没有才看 `persona.json` 的 `prompt` 字段
- 删卡时提示词和表情包一起删；**正在用的卡删不掉**，最后一张也删不掉

### 表情包

**后台 → 素材 → 表情包库**，管理的是**当前身份卡**的表情包。

文件命名规则不变：`心情+序号.后缀`，比如 `happy1.png`、`love_02.gif`。
心情只能这八个：`happy / think / confused / proud / cry / angry / sleepy / love`。

换身份卡后表情包也跟着换——每张卡一套。

## 2. 换模型 / 接口

**后台 → 模型与接口**，三套独立配置：

| 那套 | 管什么 |
|---|---|
| 聊天模型 | 纯文字对话 |
| 看图模型 | 带图那轮、`read_img`、`read_pdf` 抽图 |
| 检索翻译 | 知识库跨语言检索时把中文问题翻成英文 |

接口地址填任何 **OpenAI 兼容**的 `/chat/completions` 都行（DeepSeek、GLM、Qwen、本地 vLLM…）。
Key 填新的就覆盖，页面上只显示尾巴，留空表示不改。

---

## 3. 关掉用不上的工具

**后台 → 模型与接口 → 工具开关**。

工具分 9 组：基础 / 联网 / 知识库 / 文档与图片 / 跑代码 / 数字取证 / 嵌入式 / 计算进制 / 文本处理。

- 关掉的组，模型**看不到这些工具的定义**（省 token、少幻觉），硬调也会被拦下来
- 关掉后聊天里问相关问题，塔菲会直接说「这组工具被后台关掉了」
- **基础组建议别关**：读写文件、发表情包都靠它
- 改完下一轮对话立刻生效，不用重启

## 4. 换台服务器部署

后台有几个面板依赖特定环境，代码里做了**能力探测**：

| 面板 | 依赖 | 没有就怎样 |
|---|---|---|
| 访问流量 | 能读 `/var/log/nginx/access.log` | 导航里不显示这一项 |
| IP 黑名单 | `ufw` + root | 同上 |
| 检查更新 | 仓库是 git clone + systemd 管着 | 同上 |
| 境外 IP 拦截 | `/etc/nginx/geo/cn.conf` | 不生效 |

启动时探测，结果缓存 60 秒，接口是 `GET /api/admin/capabilities`。
所以你把项目搬到一台没有 nginx 的机器上，后台不会满屏报错，只是少了那几个面板。

### 新机器 checklist

```bash
git clone <你的仓库> && cd Agent-Deck
python -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env      # 没有就自己写一个，见 README「配置」
echo "TAFFY_ADMIN_PASSWORD=你的密码" >> .env
.venv/bin/python -m deck.auth create 管理员名 密码   # 第一个管理员
.venv/bin/python -m deck.web                          # 或者交给 systemd / docker
```

数据库是纯 SQLite（`.cache/taffy.db`），**备份就拷这一个文件**。

## 5. 知识库

仓库里**不带任何文档**（避免版权问题），自己往 `knowledge/` 里放：

```
knowledge/
  books/            教材 PDF / DOCX / Markdown
  notes/            自己的笔记
```

支持 `pdf / docx / html / md / txt / log`。放完重启（或在后台「知识库文档」里传）。

## 6. 想加自己的工具（改代码）

1. 在 `deck/tools/` 下新建一个模块，写 `SPECS = [ {function: {...}} ]` 和同名函数
2. 加进 `deck/tools/__init__.py` 的 `_MODULES`
3. 在 `TOOL_GROUPS` 里给它归个组（不然它会默认归到 `base`）

工具返回值会自动过两层保护：
- 会把外部内容带进上下文的工具（网页/文档/文件里的字）会被包进「外部内容」边界
- `run_code` 跑代码时有 `_pyguard` 审计钩子兜底（不许联网、不许碰 workspace 外面）

---

## 7. 一次性看到所有配置

**后台 → 模型与接口 → 配置总览**。

20 项部署相关配置汇总成一页，每项标了：**当前值 · 默认值 · 在哪改 · 改完要不要重启**。
改之前先看一眼，省得猜「这是 .env 里的还是后台里的」。

## 还改不了什么

- 前端深层的提示文案（错误信息、按钮文字）还写死中文，没抽成配置
- 主题色 / 字体：改 `deck/web/static/style.css`，`--line` 这些变量在主色附近
- 头像：身份卡目前用内置的 `static/avatar.jpg`；想换就覆盖那个文件
